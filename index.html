📐 خصائص الدالة الأسية f(x) = a·bˣ + k

المجال:
(-∞, +∞)
دائماً جميع الأعداد الحقيقية
المدى:
a > 0: (k, +∞)
a < 0: (-∞, k)
خط التقارب الأفقي:
y = k
المقطع الصادي:
(0, a + k)
عندما x = 0
السلوك الطرفي (b > 1):
a > 0: x→-∞, f→k; x→+∞, f→+∞
التزايد/التناقص:
a > 0, b > 1: متزايدة
a > 0, 0 < b < 1: متناقصة
